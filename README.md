# Digital Store

Projeto desenvolvido como parte do curso Full Stack, com o objetivo de praticar os que foi ensinado. O projeto simula uma loja virtual.

## Tecnologias utilizadas
 
- React
- JavaScript
- Vite
- React Router DOM
- CSS
- Lucide React

## Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/ALeticiaVieira/projeto-front-end.git
```

2. Entre na pasta do projeto:

```bash
cd projeto-front-end
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor:

```bash
npm run dev
```
